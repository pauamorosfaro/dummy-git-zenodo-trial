# Dummy Number Dataset

This repository is a test of a combined GitHub and Zenodo Sandbox workflow.

## Contents

- `data/dummy_number_sequences.csv`: dummy numerical sequences
- `CHANGELOG.md`: summary of changes between released versions

## Workflow

1. Make and review all changes in this Git repository.
2. Commit the accepted changes.
3. Create a Git tag and GitHub Release using the same version number as Zenodo.
4. Upload the identical released dataset file to a new version of the Zenodo Sandbox record.
5. Do not edit the GitHub and Zenodo copies independently.
